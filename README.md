
# NearYou 💚

**NearYou** adalah aplikasi mobile berbasis Android yang dirancang untuk membantu pengguna menemukan teman dan tempat menarik di sekitar mereka. Aplikasi ini terinspirasi dari konsep LINE Nearby dengan tampilan yang sederhana, modern, dan mudah digunakan.

## Fitur Aplikasi
- **Home:** Menampilkan halaman utama dan informasi seputar NearYou.
- **Pencarian:** Memudahkan pengguna mencari teman atau tempat berdasarkan nama.
- **Kategori:** Memfilter hasil berdasarkan kategori teman dan tempat.
- **Nearby:** Menampilkan daftar teman dan tempat beserta informasi jaraknya.
- **Navigasi:** Menyediakan menu Home, Nearby, Favorit, dan Profil.

## Teknologi
- Bahasa pemrograman: Kotlin
- Platform: Android
- IDE: Android Studio

## Tujuan
Aplikasi NearYou dikembangkan sebagai proyek pembelajaran Pemrograman Mobile untuk menerapkan penggunaan Kotlin dalam pembuatan aplikasi Android dengan antarmuka interaktif.

## Catatan
Informasi teman, tempat, dan jarak pada versi demo merupakan data contoh, bukan lokasi real-time.
